## 3. Deviations from the contract (for the orchestrator)

1. **MDX not installed.** Sections 0 and 11 say no MDX. The brief for this task listed "MDX support". The contract was followed. Decision needed from the user if MDX is wanted.
2. **`experimental.viewTransition` omitted.** Next 16.4.2 has no such config key (it is absent from the shipped config types and server code). The bundled guide `node_modules/next/dist/docs/01-app/02-guides/view-transitions.md` states View Transitions need no configuration. `ViewTransition` is exported by `react` 19.3.0 (verified: `require('react').ViewTransition` is a symbol). The export name for 5.3 is `ViewTransition`, imported from `react`.
3. **create-next-app template extras removed:** `cacheComponents`, `partialPrefetching` and the Turbopack Tailwind rule (not in the contract; Tailwind runs through PostCSS), `AGENTS.md` (its text contains an em dash and `next dev` rewrites it, so it would break the character rule; not in section 1), `README.md`, default SVGs in `public/`, `src/app/favicon.ico` (icons belong to 5.6).
4. **Engines.** `engines.node` is `>=20.9` as the contract says. vitest 5.0.5 declares `^22.12 || ^24 || >=26`, so npm prints EBADENGINE on Node 20 and on the local Node 25.8.2. Node 22 or 24 is recommended for development and Vercel.
5. **Scripts reference files not yet created:** `images` (`scripts/prepare-images.mjs`, task 4.3), `db:generate` and `db:migrate` (`drizzle.config.ts`, task 4.4). They fail until those tasks land.
